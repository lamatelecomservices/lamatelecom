# Lama Telecom — Corporate Website

Corporate marketing website for Lama Telecom, a telecom infrastructure services company specializing in network decommissioning, IT asset recovery, responsible recycling, and enterprise network solutions.

Built with **Next.js 16** (App Router), **React 19**, **Tailwind CSS v4**, and **Motion**.

## Quick Start

```bash
npm install
npm run dev     # → http://localhost:3000
npm run build   # Production build
npm run start   # Production server
```
